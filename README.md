# 結合 AI 之沉浸式 VR 駕駛：突發狀況模擬與場內外情境整合

以 Unity 製作的台灣汽車駕照考試模擬器，支援 Logitech G923 方向盤，包含五項場內考試的自動判定、導航、訓練模式，以及以強化學習訓練的「危險駕駛 AI」，讓新手在安全的虛擬環境中練習考照與應對突發狀況。

> ⚠️ **本倉庫為開發中版本，並非完整可執行版。**
> 專案使用的付費／第三方素材因授權限制未包含在內（見下方「未包含的素材」），直接開啟時部分模型、字型會顯示為遺失。

本專案為大學四年級團隊專題，此倉庫由 蔡承哲（Yurri）整理上傳。

## 主要功能

- **五項場內考試自動判定**：路邊停車、倒車入庫、S 型螺旋坡道、直線行駛、坡道定點停車，依台灣考照規則即時判定與扣分。
- **導航系統**：路網節點 A* 路徑規劃、偏離路線自動重新規劃、語音導航與小地圖。
- **模式流程**：考試模式、訓練模式、自由駕駛模式，以及計分結算與介面。
- **危險駕駛 AI（突發狀況演練）**：模擬「鬼切」等危險駕駛行為，考驗學員的反應。
- **硬體支援**：Logitech G923 方向盤、踏板、排檔與力回饋，並保留鍵盤操作。

## 強化學習鬼切車

使用 Unity ML-Agents（PPO）訓練一台會「切入學員車前方」的 AI 車，並以規則式版本作為對照。

- **觀測**：21 個觀測值（與學員車的相對位置、速度、車道資訊等）
- **訓練方式**：領域隨機化，模擬 5 種不同風格的學員
- **安全防護層**：AI 動作超出安全範圍時，改由規則式接手
- **最終模型**：`Assets/script/危險駕駛AI/機器學習/GhostCutIn_v6.onnx`

| 測試環境 | 指標 | 強化學習 v6 | 規則式 |
|---|---|---|---|
| 訓練場 | 切入成功率 | 71.1% | 55.8% |
| 訓練場 | 碰撞率 | 3.0% | 10.3% |
| 城市道路（304 次，配對測試） | 切入成功率 | 73.9% | 53.0% |
| 城市道路（304 次，配對測試） | 碰撞率 | 1.3% | 5.3% |

城市道路的成功率差異達統計顯著（p < 0.001）；碰撞率較低，但因碰撞事件少，差異未達統計顯著。城市測試使用程式模擬的虛擬學員，真人測試仍在進行中。

## 專案結構

```
Assets/
├─ Scenes/                     場景（cc.unity 為主要城市場景）
├─ scripts/                    考試判定、導航、模式系統、計分、設定選單
├─ script/危險駕駛AI/          危險駕駛 AI（規則式與強化學習）
│  └─ 機器學習/                ML-Agents 代理、自動測試工具、v6 模型
├─ script/方向盤/              方向盤與力回饋
├─ blender/                    自製 3D 模型
└─ 車流資料/                   車流與行人系統
MLTraining/                    訓練設定（GhostCutIn.yaml）與訓練批次檔
results/                       各版本訓練紀錄（可用 TensorBoard 開啟）
```

## 開發環境與開啟方式

- Unity **2022.3.62f3**
- ML-Agents（Unity 套件 com.unity.ml-agents）
- 本倉庫使用 **Git LFS** 管理模型、貼圖等大型檔案，請先安裝 Git LFS 再 clone：

```bash
git lfs install
git clone <本倉庫網址>
```

用 Unity Hub 開啟資料夾即可；第一次開啟會重新建立 Library，需要一段時間。

查看訓練曲線：

```bash
tensorboard --logdir results
```
